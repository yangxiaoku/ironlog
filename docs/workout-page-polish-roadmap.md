## 6 项核心升级清单

### 1. 动作卡片内联 GIF 动作示范（支持小图 / 大图 / 隐藏）
- **改造点**：在 `WorkoutEditorModal` 启动时批量调用既有 `/api/catalogue/exercises/details` 缓存拉取动作 `illustration.gifPath` / `frames[0].path`，替换卡片左上角静态占位图标；支持 `demoDisplayMode`（`small` 缩略图 / `large` 展开示范条 / `hidden` 隐藏）一键切换并云端同步。
- **验收**：带 GIF 的动作卡片直接呈现动态示范；无图动作平滑回退图标，不影响首屏加载速度。

### 2. 点组号弹出「组操作菜单」+ 收纳空备注还原紧凑组行
- **改造点**：
  - 点击组号（第 `N` 组）打开清晰的操作菜单面板（替代原来的盲切循环），提供：
    - 显式标签切换组类型（`常规 / 热身 / 力竭 / 递减 / 休停`）；
    - **`复制这一组`**（在下方插入同重量/次数新组）；
    - **`+ 插入递减组`**（自动在下方插入约 `80%` 重量、按步进取整的 `drop` 组）；
    - **`+ 插入休停组`**（自动插入同重量 `rest_pause` 衔接组）；
    - **`本组后休息覆盖`**（支持给单组单独指定 `restAfterSeconds`，如大重量顶峰组设 `180s`，优先级高于动作默认休息）；
    - **`编辑组备注`**（移除未填备注时默认显示的 `+ 组备注` 占位行，仅在已填写备注或编辑态时展示，显著释放手机单屏可视组数）。
- **验收**：新增纯函数单测验证复制组、80% 递减组插入、休停组插入及 `restAfterSeconds` 休息时长优先级。

### 3. 单组对比箭头（`↑ / = / ↓`）+「上次 / 历史最佳」一键切换 + 组内实时 `🏆 PR` 徽标
- **改造点**：
  - 训中并行调用既有 `POST /api/web/exercise-prs` 拉取每个动作的全时期历史 PR 基线（最高重量、最高估算 1RM、最长保持、最低辅助）；
  - 每组行与上次同序号工作组做实时对比，在已完成组旁显示轻量 `↑`（超越上次）/ `=`（持平）/ `↓`（略低）箭头；
  - 动作参考行支持一键在 **`上次记录`** 与 **`历史最佳（PR）`** 之间切换；
  - 当某组勾选完成并打破历史全时期重量或 1RM 纪录时，立即在组行亮出 **`🏆 PR`** 徽标（并触发 `pr` 触感反馈）。
- **验收**：新增纯函数单测覆盖单组 `↑/=/↓` 判定与实时 PR 突破判定（含 `lb` 折算口径）。

### 4. 训练入口页（`WorkoutView`）升级为「开练控制台」
- **改造点**：
  - 在 `WorkoutView` 顶部新增「今日开练」控制台卡片：
    - 直接展示 **今日计划（带迷你 `MuscleBodyMap`）** 或轮换下一训练日，一键开练；
    - 横向快捷条列出当前计划的 **其他训练日** 与 **已保存模板**，点一下直接预览开练；
    - 保留 **自由训练（边练边选）** 入口；
    - 内置轻量 **「训前快记体重」** 一行输入条（今日未称重时可顺手填一下直接入库，今日已称重则显示当日体重）。
- **验收**：进入「训练」Tab 一屏即可开练今日计划/其他训练日/自由训练或速记体重，无需跳回首页或计划页。

### 5. 计划主项「自动带出递增热身」开关（随目标重量自动缩放）
- **改造点**：
  - `plannedExerciseSchema` 新增可选字段 `autoWarmup?: boolean`（默认 `false`）；
  - `PlannedExerciseList` 计划编辑器增加「自动热身」开关；
  - 从计划预览页（`PlanModals`）启动训练时，对开启 `autoWarmup` 的动作自动按目标工作重量、当前场馆 `barWeight` / `enabledPlates` / `platePairs` / `warmupScheme` 生成递增热身组放在工作组前；
  - 训中「热身」区新增一键提示，手动加完热身也能清晰看到每组配片与增减片路径。
- **验收**：新增测试验证 `plannedExerciseSchema.autoWarmup` 校验及启动训练自动生成缩放热身组逻辑。

### 6. 动作内「最近历史」极速抽屉
- **改造点**：在 `WorkoutEditorModal` 每个动作的快捷栏增加 **`历史`** 按钮，点击不离开训中上下文、直接拉取 `GET /api/web/exercises/:id/history` 展示最近 8 次训练的日期、每组重量/次数/RIR 与单次最高估算 1RM，方便现场对照加减片。
- **验收**：不中断计时器与未保存草稿，随时查看当前动作近多次完整组次历史。
