# Ironlog 全站视觉与排版系统性清扫路线图（UI Visual Audit Polish）

> 基于线上真实浏览器 `390×844`（手机端全 11 页 + 训中弹窗）与 `1280×800`（桌面端）逐页截图巡检，并经 `/grill-me` 对齐的 6 项核心设计决策。

## Batch 1：4 个「较差」页面彻底翻修 + 全局基础设施修复

1. **全局路由切换滚回顶部 + 在线状态点语义修正**
   - `AppShell.tsx` / `useUiStore.ts`：`navigate(view)` 与 hash 路由切换时强制 `window.scrollTo(0, 0)`，消除切页残留 `scrollY` 停在页尾的问题。
   - `ironlog.css`：将侧边栏左下角及页头 `已登录 / 用户名` 旁的在线状态圆点由红色改为清晰绿色（`#22c55e`），消除“像报错/离线”的语义误导。
2. **登录页（`AuthScreen.tsx` + `ironlog.css`）手机端 3 标签折行修复**
   - 将登录/配对码/注册分段条从固定 2 列改为自适应 `repeat(auto-fit, minmax(0, 1fr))`（或 3 列等分单行不折行），消除手机端 `2+1` 畸形折行与右侧空洞；主提交按钮改用更克制统一的哑光风格。
3. **日历页（`CalendarView.tsx` + `ironlog.css`）排版与一致性修复**
   - 月历顶栏 `2026 年 11 月` 禁止折成两行，精简右侧按钮文案防止截断成 `刷新排期...`。
   - 修正 `排期训练` 下方操作按钮右偏问题（统一左对齐/均分）。
   - 修复 Apple 健康 5 项在 3×2 网格留第 6 格空白问题（末项跨列或采用自适应 2/3 列卡片布局）。
   - 统一 `+ 记饮食` 与 `+ 记体重` 为一致的 `.secondary-button` 描边样式。
4. **动作库（`ExercisesView.tsx` + `ironlog.css`）彻底消灭无图虚线大空框**
   - 卡片改为**「左图右文」紧凑列表卡**：有示范图展示 56×56 圆角缩略图；无图展示简洁肌群色标徽章，不再渲染半张卡高的空白占位框。
   - 顶部肌群筛选条增加右侧渐隐提示与流畅横向滚动，同时将「人体图选肌群」入口固定在可见操作行，不再被挤出首屏。
5. **成就徽章（`BadgesView.tsx` + `ironlog.css`）结构瘦身与图标提亮**
   - 由 105 枚平铺（`15,077px`）改为**按分类折叠手风琴**：默认展开「已点亮 / 冲刺中」所在分类（或前 2 个有进度分类），其余分类折叠并显示 `已点亮/总数`，一键展开。
   - 手机端改为紧凑 3 列徽章网格，压缩冗余留白；显著提高未解锁徽章图案在深色底上的轮廓亮度与对比度（同时改善首页徽章摘要槽位辨识度）。

## Batch 2：训练主链路与饮食页深度打磨

6. **训练页（`WorkoutView.tsx` + `ironlog.css`）去重与宽屏排版**
   - 移除重复的 `+ 自由训练` 按钮（保留单一清晰入口）。
   - 历史搜索框独立占满整行（手机端和桌面端均不再被同排肌群胶囊挤压截断）。
   - `主项 1RM` 仅渲染已有真实成绩的动作（过滤空 `—` 占位卡），若尚无成绩则优雅隐藏该区块。
   - 桌面端 Launchpad 内的 `MuscleBodyMap` 合理放大并对齐视觉重心；横向筛选条补充流畅边距。
7. **训中编辑器（`WorkoutEditorModal.tsx` + `ironlog.css`）单手体验与视觉降噪**
   - 为 `.set-action-menu` 内的 `组别 / 快捷 / 组后休息` 选项补齐清晰按钮描边、底色与高亮选中态。
   - 合并动作快捷栏里重复出现的 `休息 90s` 静态文案与倒计时胶囊。
   - 每组下方的单组「上次 · 填入」芯片仅对**当前下一组待完成（`is-next`）**且上次记录有效（重量/时长 > 0 且与当前输入不同）时展示，其余组保持超紧凑单行。
   - 修复 `...` 设置抽屉内 3 项分段控件在 `390px` 折成 `2+1` 的问题（紧凑字号 + 单行 3 等分）。
8. **饮食页（`DietView.tsx` + `ironlog.css`）文案去重与按钮统一**
   - 精简热量摘要区冗余文案，避免 `还差 2,200 kcal` / `— kcal` / `已摄入 0 kcal` 同屏重复与破折号占位。
   - 饮水快捷区优化换行布局，消灭孤立掉到第二行的 `自定义` 按钮。
   - 统一早/午/晚/加餐所有 `+ 添加` 按钮样式一致。

## Batch 3：首页、数据分析页与桌面端克制感收尾

9. **首页（`OverviewView.tsx` + `Charts.tsx` + `ironlog.css`）网格补齐与等高对齐**
   - `训练趋势` 下方 2×2 指标网格补齐第 4 格有效指标（如累计总容量 / 有效工作组），彻底消灭第 4 格留空。
   - 稀疏时间序列图表保留完整周期时间轴，补充浅色网格参考线与有效数据起点标记，缓解左侧大面积空黑感。
   - 桌面端 `训练趋势` 与 `肌群分布` 并排时统一卡片拉伸高度（`align-items: stretch`）并优化内部留白分布，消除左侧下方 120px 死区。
10. **数据分析页（`AnalyticsView.tsx` + `ironlog.css`）减半高度与修复半截红线**
    - 6 个时间周期胶囊改为单行横向可滚条，彻底消灭 `4+2` 畸形折行。
    - 修复 `近期状态一览` 卡片底部半截红线问题（统一为干净的卡片顶部/左侧微标或完整状态标签，不再切断网格）。
    - 手机端 7 项恢复指标改为紧凑 **2 列网格**，页面高度直接减半。
    - 桌面端底部孤立的 `计划执行率与缺练追踪` 设置跨全宽（`grid-column: 1 / -1`），消除右侧 50% 死白；修复 ACWR 滑块右端气泡贴边裁切。
11. **桌面端设置页（`SettingsView.tsx` + `ironlog.css`）按钮宽度克制**
    - 为桌面端 `Apple 健康` 主按钮（`配置 / 导出主快捷指令`）、手动同步双按钮及 `.shortcut 文件 / 手机 Base64` 切换条设置合理的 `max-width`（不再盲目拉满 800px 全宽）。

## 验收标准
- 每批完成后必须全部通过：`npm run typecheck`、`npm run typecheck:web-react`、`npm run check:web`、`npm run build`、`npm test`（含新增视觉结构回归测试）。
- 每批提交推送 `origin/main` 并部署至 VPS 验证公网 `/health` 与 `/app/` 返回 `200`。
- 全部 3 批部署完成后，通过浏览器对手机端 `390×844` 与桌面端 `1280×800` 做二次复拍验证，确认零横向溢出且上述全部缺陷已修复。
